Ett API (Application Integration Interface) är ett gränssnitt som låter olika program kommunicera med varandra. Det definierar hur en klient kan begära data eller funktioner från en server. 

APIer användes ofta över [[HTTP]] och returnerar data i format som [[JSON]] eller [[XML]], samt [[Status Codes]].  Den vanligaste *API-stilen* är [[REST]], men [[SOAP]] används också i äldre legacy system.
